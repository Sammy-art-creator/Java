# ☕ Java

Repositorio con mis **ejercicios de práctica en Java** 💻✨

## 📂 Contenido

- 📘 **Java I** → Primeros ejercicios de práctica
- 📗 **Java II** → Ejercicios de nivel intermedio

## 🎯 Objetivo

Practicar y reforzar los conceptos básicos de programación en Java: variables, condicionales, bucles, métodos y más 🚀

## ▶️ Cómo ejecutar los ejercicios

1. 📥 Clona el repositorio:
   ```bash
   git clone https://github.com/Sammy-art-creator/Java.git
   ```
2. 📁 Abre la carpeta en tu IDE favorito (IntelliJ, Eclipse, VS Code...)
3. ⚡ Ejecuta el archivo `.java` que quieras probar
